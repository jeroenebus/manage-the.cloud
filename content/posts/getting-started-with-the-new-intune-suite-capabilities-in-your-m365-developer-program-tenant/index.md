Last week Microsoft released a lot of new Intune features. But most of them are only available for users with an Intune Suite add-on. A few worth noting are:

- Microsoft Intune Enterprise Application Management

- Microsoft Intune Advanced Analytics 
 - Device query 

[**https://techcommunity.microsoft.com/t5/microsoft-intune-blog/what-s-new-in-microsoft-intune-january-2024/ba-p/4036593**](https://techcommunity.microsoft.com/t5/microsoft-intune-blog/what-s-new-in-microsoft-intune-january-2024/ba-p/4036593)

But what if you want to try these products in your M365 Developer Program tenant?

Well, this is possible with a 90-day trial of the Intune Suite! Let’s check out how to easily enable the 90-day trial?

In your Intune tenant go to **“Tenant administration”**.

![Screenshot: In your Intune tenant go to “Tenant administration”](/wp-content/uploads/2024/02/image-852x1024.png)

In the **“All add-ons”** section click on **“View details”** in the **“Microsoft Intune Suite”** part of the table.

![Screenshot: In the “All add-ons” section click on “View details” in the “Microsoft Intune Suite” part of the…](/wp-content/uploads/2024/02/image-5-1024x274.png)

Click on **“To try or buy, go to Microsoft 365 admin center”**.

![Screenshot: Click on “To try or buy, go to Microsoft 365 admin center”](/wp-content/uploads/2024/02/image-4.png)

You will be redirected to the Admin Portal where you can start the **“Free trial”**.

![Screenshot: You will be redirected to the Admin Portal where you can start the “Free trial”](/wp-content/uploads/2024/02/image-6.png)

Click on **“Try now”**.

![Screenshot: Click on “Try now”](/wp-content/uploads/2024/02/image-7.png)

You will get an order receipt, click on **“Continue”**.

![Screenshot: You will get an order receipt, click on “Continue”](/wp-content/uploads/2024/02/image-8.png)

Your 90 days trial is now active.

![Screenshot: Your 90 days trial is now active](/wp-content/uploads/2024/02/image-9-1024x461.png)

Now is possible to test new functionalities like **“Enterprise App Catalog”**!

Tip: check out [**Peter van der Woude’s**](https://twitter.com/pvanderwoude) blog about Getting started with the Enterprise App Catalog:

[**Getting started with Enterprise App Management – All about Microsoft Intune (petervanderwoude.nl)**](https://www.petervanderwoude.nl/post/getting-started-with-enterprise-app-management/)

![Screenshot: Getting started with Enterprise App Management – All about Microsoft Intune (petervanderwoude.nl)](/wp-content/uploads/2024/02/image-10-1024x463.png)

And also **“Device query”**.

Tip: to learn all about **Device query** check the GitHub page of [**Ugur Koc**](https://twitter.com/UgurKocDe) out for all kind of sample queries:

[**GitHub – ugurkocde/IntuneDeviceQuery: This repository contains a wide array of KQL Queries ready for you to easily copy, paste, and execute within Intune.**](https://github.com/ugurkocde/IntuneDeviceQuery)

![Screenshot: This repository contains a wide array of KQL Queries ready for you to easily copy, paste, and…](/wp-content/uploads/2024/02/image-11-860x1024.png)

Hopefully, this helps you to get familiar with these new capabilities and discover all the new possibilities that are possible in your development tenant.
